# buildBIDS

Utilities for converting the internal HarmonizedMRI data organization into a BIDS-compatible dataset for sharing with collaborators.

## Purpose

The scripts in this folder build the **source BIDS dataset** from the internal HarmonizedMRI directory structure.

The source BIDS dataset contains the canonical imaging data acquired during each scan session, including:

* T1-weighted anatomical images
* BOLD fMRI (product and Pulseq)
* Canonical B<sub>0</sub> field maps
* Magnitude images associated with the field maps

Derived data products (for example, sensitivity maps, alternative field maps, and preprocessed functional data) are **not** written by these scripts. Those belong under the BIDS `derivatives/` hierarchy and are generated by separate pipelines.

## Internal source organization

Each scan session is expected to have the following layout:

```text
sub00012-umich-mr750-20250115/
├── anat/
│   ├── T1w.nii.gz
│   └── T1w.json
│
├── fmap/
│   ├── fieldmap.nii.gz
│   ├── fieldmap.json
│   ├── magnitude.nii.gz
│   ├── magnitude.json
│   ├── sens.mat
│   └── sens.json
│
├── product/
│   ├── task_run1.h5.nii
│   ├── task_run2.h5.nii
│   ├── task_run3.h5.nii
│   └── task_run4.h5.nii
│
└── pulseq/
    ├── task_run1.h5.nii
    ├── task_run2.h5.nii
    ├── task_run3.h5.nii
    └── task_run4.h5.nii
```

Only the canonical BIDS images are copied into the source dataset.

Currently, the following files are **not** copied:

* `sens.mat`
* `sens.json`
* registration images
* intermediate reconstruction products
* preprocessing outputs

These will instead be stored under the BIDS `derivatives/` hierarchy.

## Current functionality

Currently implemented:

* Copy T1-weighted anatomical images.
* Copy canonical field maps and magnitude images.
* Copy product BOLD images.
* Copy Pulseq BOLD images.
* Repair Pulseq NIfTI headers using the corresponding product image.
* Convert internal session names into BIDS subject/session labels.
* Skip existing output files by default.

## Pulseq BOLD images

Pulseq reconstructions are modified before being written to the BIDS dataset.

The following operations are performed:

* Copy the NIfTI header from the corresponding product image.
* Preserve the reconstructed image dimensions.
* Set voxel size to 2.4 × 2.4 × 2.4 mm.
* Set TR to 0.8 s.
* Flip the first image dimension to match the product orientation.
* Scale the image and save as `int16`.

## Usage

```matlab
srcRoot = '/path/to/srcRoot';
bidsRoot = '/path/to/bidsRoot';

buildBIDS(srcRoot, bidsRoot);
```

`buildBIDS` scans all session directories in `srcRoot` and copies the supported imaging data into the corresponding BIDS session.
